1. Start Here

Python is a readable general-purpose programming language used for automation, web development, data work, games, scripting, and many other tasks.

Language

Python is the language you use to describe what your program should do.

Interpreter

The Python interpreter runs your Python code.

Editor

Use an editor such as VS Code, PyCharm, or another code editor to write programs.

Your first program

print("Hello, world!")
Tip: Python uses indentation to define blocks of code, so keep indentation consistent.

4. Control Flow

Conditions

score = 82

if score >= 90:
    print("Excellent")
elif score >= 70:
    print("Good")
else:
    print("Keep practicing")

For loops

for number in range(5):
    print(number)

This prints 0 through 4.

While loops

count = 3
while count > 0:
    print(count)
    count -= 1

break and continue

for number in range(10):
    if number == 5:
        break
    print(number)

5. Lists, Tuples, Sets, and Dictionaries

Lists

fruits = ["apple", "banana", "orange"]

fruits.remove("banana")

for fruit in fruits:
    print(fruit)

Dictionaries

6. Functions

Functions let you package reusable behavior.

def greet(name):
    return "Hello, " + name

message = greet("Alex")
print(message)

Parameters and defaults

def power(number, exponent=2):
    return number ** exponent

print(power(5))
print(power(5, 3))

Type hints

def add(a: int, b: int) -> int:
    return a + b

7. Errors and Exceptions

Learning to read error messages is a major programming skill.

try:
    number = int(input("Enter a number: "))
    print(10 / number)
except ValueError:
    print("Please enter a valid integer.")
except ZeroDivisionError:
    print("You cannot divide by zero.")
try:
    print("Working...")
finally:
    print("This always runs.")
Good habit: Catch specific exceptions instead of using a broad except: for everything.

8. Files

Read a file

with open("notes.txt", "r", encoding="utf-8") as file:
    content = file.read()

print(content)

Write a file

with open("notes.txt", "w", encoding="utf-8") as file:
    file.write("Hello from Python!")

The with statement helps make sure the file is closed properly.

9. Modules and Packages

import math

print(math.sqrt(81))
print(math.pi)

Import a specific name

from random import randint

number = randint(1, 100)
print(number)

Install a third-party package

python -m pip install package_name

Only install packages you trust and understand.

10. Object-Oriented Programming

class Dog:
    def __init__(self, name):
        self.name = name

    def bark(self):
        print(self.name, "says woof!")

dog = Dog("Buddy")
dog.bark()
Class

A blueprint for objects.

Object

An instance created from a class.

Attribute

Data stored on an object.

Method

A function belonging to a class.

Example: Number Guessing Game

import random

secret = random.randint(1, 100)

while True:
    guess = int(input("Guess the number: "))

    if guess < secret:
        print("Too low!")
    elif guess > secret:
        print("Too high!")
    else:
        print("Correct!")
        break

12. Recommended Learning Path

  1. Print statements and variables
  2. Strings and numbers
  3. Conditions
  4. Loops
  5. Lists and dictionaries
  6. Functions
  7. Exceptions
  8. Files
  9. Modules and packages
  10. Classes and objects
  11. Build several small projects
  12. Choose a direction such as web development, automation, data, or games
Remember: You do not need to memorize everything. Learn to read documentation, experiment, understand errors, and break large problems into smaller ones.
