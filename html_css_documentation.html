HTML & CSS Documentation

A beginner-friendly guide to building web pages with HTML and styling them with CSS.

1. Start Here

HTML describes the structure and meaning of a web page. CSS controls its appearance and layout.

HTML

Think of HTML as the skeleton and content of the page.

CSS

Think of CSS as the visual design: colors, spacing, typography, and layout.

Browser

The browser reads HTML and CSS and renders the result on screen.

Your first HTML file

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My Page</title>
</head>
<body>
  <h1>Hello, world!</h1>
  <p>My first web page.</p>
</body>
</html>
Tip: Save the file with a .html extension, then open it in a browser.

2. HTML Fundamentals

HTML uses elements, usually written with an opening tag, content, and a closing tag.

<p>This is a paragraph.</p>

Common elements

ElementPurpose
<h1> to <h6>Headings, from most important to least important.
<p>Paragraph.
<div>Generic block container.
<span>Generic inline container.
<strong>Strong importance.
<em>Emphasis.
<br>Line break.

Attributes

Attributes add information or behavior to an element.

<p class="intro">Hello!</p>
<img src="photo.jpg" alt="A mountain">

Here, class, src, and alt are attributes.

Semantic HTML

Semantic elements communicate what a section means instead of simply acting as generic containers.

<header>Site header</header>
<nav>Navigation</nav>
<main>Main content</main>
<article>An article</article>
<section>A section</section>
<footer>Footer</footer>

4. Links and Images

Links

<a href="https://example.com">Visit Example</a>

Images

<img src="cat.jpg" alt="A sleeping cat">

The alt attribute provides a text alternative for people who cannot see the image and for cases where the image cannot load.

Audio and video

<audio controls src="music.mp3"></audio>

<video controls width="640" src="video.mp4"></video>

5. Forms

Forms collect information from users.

<form>
  <label for="name">Name</label>
  <input id="name" name="name" type="text">

  <label for="email">Email</label>
  <input id="email" name="email" type="email">

  <button type="submit">Send</button>
</form>

Useful input types

text, email, password, number, date, checkbox, radio, and file.

6. CSS Fundamentals

A CSS rule has a selector and declarations.

p {
  color: navy;
  font-size: 18px;
}

Selectors

/* Element selector */
p { color: blue; }

/* Class selector */
.card { padding: 20px; }

/* ID selector */
#main-title { font-size: 40px; }

/* Multiple selectors */
h1, h2 { font-family: sans-serif; }

Connecting CSS to HTML

<link rel="stylesheet" href="style.css">

Colors and typography

body {
  background: #f5f5f5;
  color: #222;
  font-family: Arial, sans-serif;
}

h1 {
  font-size: 2.5rem;
  font-weight: 700;
}

7. The CSS Box Model

Every element can be thought of as a box consisting of content, padding, border, and margin.

.box {
  width: 300px;
  padding: 20px;
  border: 2px solid black;
  margin: 30px;
}

Flexbox

Flexbox is useful for arranging items in one dimension: a row or a column.

.container {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 20px;
}

CSS Grid

Grid is especially useful for two-dimensional layouts.

.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}

8. Responsive Design

Responsive design lets a page adapt to different screen sizes.

/* Default styles */
.cards {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}

/* Smaller screens */
@media (max-width: 700px) {
  .cards {
    grid-template-columns: 1fr;
  }
}

The viewport meta tag is also important on mobile devices:

<meta name="viewport" content="width=device-width, initial-scale=1.0">

9. Practice Project

Build a simple personal profile page using the concepts in this guide.

  1. Create an HTML document.
  2. Add a header with your name.
  3. Add an image with useful alternative text.
  4. Write a short introduction.
  5. Create a list of hobbies or skills.
  6. Add links to a few websites.
  7. Use CSS to change colors, spacing, fonts, and layout.
  8. Use Flexbox or Grid for at least one section.
  9. Add a media query so the page works well on a small screen.

Mini challenge

<!-- Build this structure yourself -->
<header>
  <h1>Your Name</h1>
</header>

<main>
  <section>
    <h2>About Me</h2>
    <p>...</p>
  </section>

  <section>
    <h2>My Skills</h2>
    <ul>
      <li>...</li>
    </ul>
  </section>
</main>
Learning path: Learn HTML structure first, then basic CSS, then the box model, Flexbox, Grid, responsive design, and finally JavaScript.
